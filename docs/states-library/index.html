#States Library

The States Library is a directory of states-data that one can load into TypeRoof Shell for different purposes like demos, tutorials, examples, and testing.

If you don’t know what to do with the files provided here, go to the TypeRoof User Kit and learn how to load states into TypeRoof Shell.
